# ML Parity Tooling (archived Python reference)

The desktop app runs its face pipeline **fully on ONNX Runtime in TypeScript**
(`packages/desktop/src/main/ml/`) — no Python is needed at runtime. This folder archives
the **Python reference scripts** that were used once, during development, to
prove the TypeScript port matches the original insightface behavior.

| File | Purpose | When you need it |
|---|---|---|
| `golden.json` | Frozen "answer key": bbox / kps / M / embedding per face, generated by insightface 0.7.3 (`buffalo_l`, det_size 640×640). The dev test `verify:pipeline` compares the TS pipeline output against it. | Development only. Not read at runtime. |
| `gen_fixtures.py` | The script that **produced** `golden.json` (runs inside the old Python API container / any insightface env). | Only if you ever regenerate the golden fixtures (e.g. after changing models or det_size). |
| `parity_cluster.py` | Python clustering reference — scans the same LFW photos and prints "photo personIndex". Diffed against `packages/desktop/scripts/parity-cluster.ts` output (`packages/desktop/data/parity-node.txt`) to prove clustering parity. | Only if you re-verify clustering parity. |

## How the pieces fit

```text
Python insightface (once)  ──gen_fixtures.py──▶  golden.json (frozen)
                                                            │
TypeScript port (packages/desktop/src/main/ml/)  ──verify:pipeline──▶ compare → PASS/FAIL

Python clustering reference (parity_cluster.py)  ◀──diff──  packages/desktop/scripts/parity-cluster.ts
```

## Verify parity

```bash
cd desktop && bun run verify:pipeline    # IoU ~0.999, cosSim ~0.9999, umeyama M diff ~1e-5
cd desktop && bun run parity:cluster     # clustering assignments; diff vs parity_cluster.py
```

## Why this folder exists

`services/` (the Python/FastAPI backend) was removed — the desktop is 100% local
(ONNX + SQLite) and the only remaining backend is the Hono in-app-update service
(`packages/backend/`). These three files were **moved out** rather than deleted so the
parity story (and the ability to regenerate fixtures) survives, documented in one
place.
